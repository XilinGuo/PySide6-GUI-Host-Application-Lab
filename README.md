# PySide6-GUI-Host-Application-Lab
An experimental PySide6 repository that guides readers through building a serial host application from scratch to control RGB LEDs on a microcontroller. It also includes a simulator, allowing you to verify the PC application even without physical hardware.


这是一个PySide上位机实验仓库，带领读者从零开始构建一个串口上位机程序，实现对单片机彩色LED灯的控制，仓库内包含仿真器可以在无单片机的情况下验证上位机程序。
